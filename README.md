# Sistema de Recomendação de Cursos e Capacitações Profissionais

Projeto da disciplina **Projeto Aplicado III** — Universidade Presbiteriana Mackenzie, Banco De Dados.

##  Sobre o projeto

Sistema de recomendação que sugere cursos e capacitações profissionais a partir do perfil do usuário (escolaridade, área de interesse, habilidades atuais), aproximando a oferta de qualificação das demandas do mercado de trabalho.

##  Objetivos de Desenvolvimento Sustentável (ODS)

Este projeto tem caráter extensionista e está alinhado a:

- **ODS 4 — Educação de Qualidade**
- **ODS 8 — Trabalho Decente e Crescimento Econômico**

##  Base de dados

**Coursera Courses Dataset 2021** — Khushee Kapoor (Kaggle)
 https://www.kaggle.com/datasets/khusheekapoor/coursera-courses-dataset-2021

~890 cursos, com colunas de título, instituição, tipo de certificado, nota, dificuldade, número de matriculados e descrição.
